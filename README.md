# Private Mod Lars SA Expand
# Lars 的太空时代扩展

私人用的 Factorio Mod，基于 Bob 和 Angle 系列 mod 开发

不推荐在该 mod 上直接进行修改，如有需要可以打包后在其他 mod 上添加依赖并进行后续修改

## ChangeLog

### Recent: Ver 0.2.2 (Oct 23, 2026)

**Change:**
- 修改祝融星的矿物生成
    - 将方解石矿脉换成火成岩矿脉
    - 新增火成岩处理，可以获得花岗石、正长石、安山石三种石材
    - 新增基于这三种石材的岩浆处理，可以获得粗铁、粗铜、蒸汽和空气
    - 新增粗铁粗铜铸造，可制造铁板、铜板、钢板
- 修改祝融星科技的顺序和安排，钨相关科技通过新地星解锁
- 修改大型采矿机和冶金科技包的制造素材
- 将原铸造厂更换为岩浆精炼厂

**Balance:**
- 空气压缩机只能在新地星和草星放置
- 钨铜合金需要的液体从原版factorio的熔融铜更换为angel熔融铜
