# Private Mod Lars SA Expand
# Lars 的太空时代扩展

私人用的 Factorio Mod，基于 Bob 和 Angle 系列 mod 开发

不推荐在该 mod 上直接进行修改，如有需要可以打包后在其他 mod 上添加依赖并进行后续修改

## ChangeLog

### Recent: Ver 0.1.8 (Oct 14, 2026)
**Change:**
- 新增用于测试的 TFMG 散热片
- 通过 TFMG_thermal 模组引入太空的热量管理系统，对制造机和熔炉添加了热量系统
**Balance:**
- 调整部分制造建筑允许的建造气压
    - 部分基础机器（基础型号制造机、换热器、蒸汽机、炮塔、激光炮塔、分选器、高炉、铸造机、感应炉）无法在太空建造
    - 地雷和巨炮无法在太空建造
    - 除上述列出的天使矿石处理、精炼和铸造机器的高级版本以外，其他矿石处理、精炼和铸造机器无法在太空建造
    - 天使生物系列机器和地下水抽取泵只能在地星和草星建造
    - 天使化工系列机器（除化工厂、高级化工厂、电锅炉）以外的机器无法在太空建造
- 调整线圈制造速度（电磁线圈 2s->0.5s，高强度和超级线圈 2s->1s）
- 调整核燃料相关科技所需要的研究包种类（为部分后续科技添加前置科技需要的科技包）
**Fix:**
- 修复火箭燃料科技不需研究直接解锁的bug
