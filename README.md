# Private Mod Lars SA Expand
# Lars 的太空时代扩展

私人用的 Factorio Mod，基于 Bob 和 Angle 系列 mod 开发

不推荐在该 mod 上直接进行修改，如有需要可以打包后在其他 mod 上添加依赖并进行后续修改

## ChangeLog

### Recent: Ver 0.2.12 (Nov 04, 2026)

**Change:**
- 新增光催化熔炼科技和配方，高效产出合金和钨
- 新增复杂浇筑的相关配方和科技，可以从熔融金属直接浇筑复杂零件
- 新增粒子流体电子、高能光子及相关配方和科技（光电效应、粒子加速器、电子加速）
- 新增流体熔融钨，在高能光子加热下可以融化钨，并进行高效的钨浇筑制造
