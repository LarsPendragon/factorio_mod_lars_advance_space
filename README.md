# Private Mod Lars SA Expand
# Lars 的太空时代扩展

私人用的 Factorio Mod，基于 Bob 和 Angle 系列 mod 开发

不推荐在该 mod 上直接进行修改，如有需要可以打包后在其他 mod 上添加依赖并进行后续修改

## ChangeLog
### Recent: Ver 0.1.6 (Oct 12, 2026)
**Feature:**
- 新增科技固体火箭燃料、简易和标准隔热瓦、固体燃料火箭组件及相关配方，用于平衡性调整
- 新增物品铝粉，用于和火箭推进剂制造固体火箭燃料
- 新增更高等级的火箭发射井、物流接驳站

**Balance:**
- 修改火箭发射井配方，调整依赖科技，并调整火箭发射井性能，使其变为化工研究包（蓝瓶）等级的科技
- 基于固体火箭燃料可以制造火箭组件，虽然速度更慢，但所需科技和物品难度降低
- 调整火箭发射井支持的配方列表，可以选择不同性能的火箭组件制造配方
- 调整物流接驳站的容量
    - 物流接驳站:20；物流接驳站Mk2:60
    - 扩展接驳站Mk2:50
- 火箭燃料不能被用于普通载具上

**Fix:**
- 修复 control.lua 中 on_nth_tick 函数导致的多人联机崩溃问题（Ver 0.1.4a）
