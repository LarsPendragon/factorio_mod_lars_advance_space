# Private Mod Lars SA Expand
# Lars 的太空时代扩展

私人用的 Factorio Mod，基于 Bob 和 Angle 系列 mod 开发

不推荐在该 mod 上直接进行修改，如有需要可以打包后在其他 mod 上添加依赖并进行后续修改

## ChangeLog

### Recent: Ver 0.1.10 (Oct 16, 2026)

**Change:**
    - 新增太空排气阀，可以排掉多余的氢气和氧气
    - 调整星岩处理配方，金属星岩产出铁质碎屑、铜质碎屑；氧化星岩产出铑金矿；碳质星岩产出粉碎煤、铅矿
    - 调整推进器氧化剂和推进器燃料的配方，需要氢气和氧气参与制造
    - 新增配方：基于煤滤芯的水净化
    - 引入铑矿系列配方，包含铑金矿、铑金矿泥、铑粉、铑催化剂等；并新增铑处理系列配方和科技

**Balance:**
    - 调整部分太空平台配方的解锁顺序
    - 调整部分机器，配合配方使其在太空也能建造

**Fix:**
    - 修复 bob 部分配方仍需要液体燃料的问题，改为柴油
