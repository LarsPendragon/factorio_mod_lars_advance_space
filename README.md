# Private Mod Lars SA Expand
# Lars 的太空时代扩展

私人用的 Factorio Mod，基于 Bob 和 Angle 系列 mod 开发

不推荐在该 mod 上直接进行修改，如有需要可以打包后在其他 mod 上添加依赖并进行后续修改

## ChangeLog

### Recent: Ver 0.1.12 (Oct 20, 2026)

**Change:**

- 增加整体开关控制是否开启新地星的鱼类、植物的变质体系，并根据类别设置变质时间
    - 默认时间：鱼类、河豚 7550秒；生肉 3600秒；植物 14400秒；种子 21600秒；植物产物 7550秒
    - 天使生物配方保证产物新鲜度最大
- 新增太空散热片，辅助太空机器散热
- 新增液态氢气、氧气、氮气制气态气体的配方

**Balance:**
- 调整部分天使矿物熔炼建筑的最大工作温度和最大安全温度
- 调整部分配方的分类和位置顺序
- 调整火箭发射井的前置科技，保证解锁时能够正常建造
- 调整需要温度管理的机器列表及部分温度数值
- 调整部分配方拼写错误的单词（可能会导致加载游戏时弹窗提示，无实际影响）

**Fix:**
- 修复太空排气配方解锁问题
