# Private Mod Lars SA Expand
# Lars 的太空时代扩展

私人用的 Factorio Mod，基于 Bob 和 Angle 系列 mod 开发

不推荐在该 mod 上直接进行修改，如有需要可以打包后在其他 mod 上添加依赖并进行后续修改

## ChangeLog

### Recent: Ver 0.2.8 (Oct 30, 2026)

**Change:**
- 新增机器射线接收器，流体宇宙射线及相关科技和配方
    - 宇宙射线可以参与铑矿的自催化处理（替代原来的氢气），并可以将原版弹夹和穿甲弹夹转换为 bob 弹夹
- 新增流体光子及相关科技和配方
    - 新增熔炼二氧化钛的配方
    - 二氧化钛和光子可以制作光子催化剂，光子催化剂参与橙瓶的制造
    - 光催化剂可以从岩浆制取硅酸钇光容器，可以将光子存储一小时
- 新增机器粒子实验室，负责光子相关物品的制造
- 宇宙射线和光子无法被正常存储在管道和储液罐中，每5s会检查一次，将所有存储的流体移除一半

**Balance:**
- 调整部分祝融星科技顺序和需要的科技包类型
- 橙瓶（冶金科技包）新增光子催化剂作为原材料，解锁条件变为制造光子催化剂
