# Private Mod Lars SA Expand
# Lars 的太空时代扩展

私人用的 Factorio Mod，基于 Bob 和 Angle 系列 mod 开发

不推荐在该 mod 上直接进行修改，如有需要可以打包后在其他 mod 上添加依赖并进行后续修改

## ChangeLog

### Recent: Ver 0.2.6 (Oct 28, 2026)

**Change:**
- 新增祝融星的物品：变质岩（可生产方解石、板岩和片岩）以及沉积岩（可生产方解石、砂岩和页岩）
- 新增制造变质岩和沉积岩的配方
- 新增通过岩浆、特定岩石和催化剂将岩浆转化为熔融矿物的科技和配方
- 新增从页岩油提取多相油和热水的配方
- 新增破碎部分岩石，可以获得碎石、矿渣和部分矿物的配方

**Balance:**
- 补充保证天使生物配方产物新鲜度最大
- 调整部分配方的方解石从原版方解石更换为新方解石
